# The Oskars — public site

This repository holds a generated, privacy-audited static build of
[The Oskars](https://github.com/OskarHolmstedt/the_oskars), a local-first
film-awards tracking app. It is published by that private repository's
`deploy-pages` workflow and is not edited directly — every file here is
overwritten on each deploy.

Served via GitHub Pages. Your own data, if you use the app from this site,
stays in your browser only; nothing is uploaded anywhere.
