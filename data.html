Letterboxd export

Select the original ZIP from Letterboxd. The browser reads it locally and previews watched films, ratings, diary facts, tags, and watchlist changes. Awards and rankings are never imported.

The ZIP never leaves this browser.

Google Sheets

Build and review an unpublished proposal from configured private sheet ranges. Applying never publishes canonical JSON.

Official Oscars results

Preview a bracket-shaped TSV or the long-form historical Oscars export as official winners and nominees. Only categories used by this app are retained. This refresh never changes personal awards, ranks, films, or edit history.

Backup & restore

Download a complete JSON snapshot, or select one to preview a proposal. Merge adds films and awards; replace proposes a full draft replacement. Neither path publishes canonical JSON.

Cloud sync

Signed-in devices keep this workspace synced through Firestore. A manual sync runs the same reconciliation the app already runs automatically after every save and on sign-in. Loading the complete archive from the cloud previews it as a replace proposal below - nothing changes until you apply it.

Clear local data

Replace the browser database with an empty personal archive that stays empty after reload. Bundled factual Oscars results remain available. Download a backup first.

Delete opinion data

Remove award placements, ratings, personal scores, reviews, interest tiers, and notes, and reset the all-time order back to a rating / release-year / title default. The factual archive — films, watch dates, credits, metadata, tags, franchises, projects — stays. A backup downloads first.
