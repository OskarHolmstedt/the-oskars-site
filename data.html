New here? The Letterboxd export panel below is the fastest way to bring in an existing collection. This page also reviews archive-file changes, publishes canonical data, keeps a portable backup, inspects health, and fetches TMDB images.

Start here if you already track films elsewhere

Letterboxd export

Select the original ZIP from Letterboxd (Settings → Import & Export → Export your data). The browser reads it locally and previews watched films, ratings, diary facts, tags, and watchlist changes. Awards and rankings are never imported — those are yours to set up here. After you apply it, the Fetch metadata panel below automatically starts pulling in missing posters and details for the newly imported films (checking films other Shared Edition members have already looked up first, to avoid duplicate TMDB requests) — no need to start a manual batch right away.

The ZIP never leaves this browser.

Backup & restore

Download a complete JSON snapshot, or select one to preview a preview. Update adds films and awards while keeping the rest; replace rebuilds this browser's archive from the file. Neither choice publishes anything.

Clear local data

Replace the browser database with an empty personal archive that stays empty after reload. Bundled factual Oscars results remain available. Download a backup first.

Delete opinion data

Remove award placements, ratings, personal scores, reviews, interest tiers, and notes, and reset the all-time order back to a rating / release-year / title default. The factual archive — films, watch dates, credits, metadata, tags, franchises, projects — stays. A backup downloads first.

Build your Oskars

Reset rankings

Recompute the all-time order for a release-year range (blank fields = every film) back to a default: rating, then release year, then title. Ratings, awards, and everything else stay untouched. A backup downloads first.

Remove awards

Remove award placements for the chosen period types and release-year range (blank fields = every year). Ratings, ranks, and everything else stay untouched. A backup downloads first.

Fetch film details and images

Fill in missing film details, posters, and portraits from TMDB. A small batch starts immediately; the all-missing actions show their current item count and may take several minutes.
